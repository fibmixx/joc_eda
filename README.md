Project for the EDA (Data Structures and Algorithms) course at FIB UPC.

Project where the students would have to create an AI that would win in a 1v1v1v1 game, where the main objective was to get as much punctuation as possible by either painting the map in your color, obtaining items or defeating enemies. Once all the students submitted their codes, all AIs would compete against each other.

My version of the AI can be found on `AISohyun.cc` and its variations.
